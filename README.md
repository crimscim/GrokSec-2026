# GrokSec-2026

**AI-Powered Security Scanner for 2026**

Modern, fast, and relevant security tool built for today's threats.

## Features
- Real-time vulnerability scanning
- AI-assisted threat detection (integrates with Grok/xAI models)
- Support for Web3, smart contracts, and traditional apps
- Modern CLI + Web UI
- Automated reporting with severity scoring

## Quick Start
```bash
pip install groksec
python -m groksec scan --target example.com
```
